# Lights Out（ライツアウト）

ブラウザで遊べる5×5のパズルゲームです。HTML、CSS、JavaScriptのみで実装しており、外部ライブラリ、通信、ビルドは不要です。スマートフォン、タブレット、PCに対応しています。

## 遊び方

1. マスをクリックまたはタップすると、そのマス自身と上下左右のライトが反転します。端や角では、盤面内にあるマスだけが反転します。
2. 25個すべてのライトを消すとクリアです。現在の手数と点灯数が表示され、クリア時には結果メッセージが出ます。
3. **リセット**で同じ問題の初期状態に戻り、手数も0に戻ります。
4. **新しい問題**で別の問題に切り替わります。

キーボードではTab / Shift+Tabでマスやボタンを選び、Enter / Spaceで操作できます。クリア後は盤面操作を停止します。リセットまたは新しい問題で再び遊べます。

### 問題の生成

全消灯の盤面にランダムな合法操作を加えて生成します。同じ操作をもう一度行えば元に戻るため、必ず解けます。全消灯の問題と直前と同じ初期盤面は除外します。解答手数の最小化や難易度の保証は行いません。

## ファイル構成

- `index.html`：画面、操作ボタン、遊び方
- `style.css`：レスポンシブなレイアウトとライトの表示
- `script.js`：反転処理、問題生成、手数、クリア判定、リセット

## ローカルで起動

`index.html`をブラウザで開くだけで遊べます。

ローカルサーバーを利用する場合は、このディレクトリで以下を実行します（Python 3がある場合）。

```sh
python3 -m http.server 8000
```

ブラウザで <http://localhost:8000> を開きます。終了はCtrl+Cです。

## GitHub Pagesで公開

1. このプロジェクトのファイルをGitHubリポジトリのルートにコミットしてpushします。
2. リポジトリの **Settings → Pages** を開きます。
3. **Build and deployment → Source** で **Deploy from a branch** を選びます。
4. 公開するブランチ（例：`main`）と **/ (root)** を選んで **Save** します。
5. デプロイ完了後、Pages画面に表示される公開URLを開きます。

ビルドコマンドや追加の設定ファイルは不要です。CSSとJavaScriptは相対パスで読み込むため、プロジェクト用のPages URLでも動作します。
